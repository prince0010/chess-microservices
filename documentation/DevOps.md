# Tools DevOps used in the server.

1. C-Advisor is used as a docker image service to plot ports and catch traffic.
2. Prometheus is used as a docker image service to control RAM and CPU Cores resources.
3. Grafana is used as a docker image service to display in UI graphics and charts the content of prometheus.
4. Redis module is used as a docker image service and developed to cache some data needs to be cached and avoid repeated requests to microservices.
