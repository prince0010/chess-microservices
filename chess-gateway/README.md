# Client Gateway for Chess - Microservices - Backend - Server

This is the microservice that works as gateway. This will distribute all endpoints and data between external public petitions and our private server.

## Installations

1. Class validator and class transformer
   `npm i class-transformer class-validator`

2. NestJs Microservices
   `npm i @nestjs/microservices`

3. Dotenv and joi to handle environment variables
   `npm i dotenv joi`

4. Nats
   `npm i nats`
